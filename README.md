# Systems Completion
## Engineering & Handover Portfolio
A practical study of industrial systems completion, construction turnover, commissioning readiness, and project handover.

### What am I doing here
In order to deepen my understanding of systems completion and build underlying skills I have decided to make a guided project. Chatgpt will guide me through establishing this. I intend to keep a daily log of what I have done as well as what discussion I had with Chatgpt. For the purposes of fun and practicality, I will refer to chatgpt as the oracle and my daily log will be called captains_log. Everything is tracking using git and each day will have an entry in the captains_log. So that decisions can be tracked chronologically. I will avoid branching merging and rebasing to avoid loosing history. But if there is some tool I have to fix I may handle it with that. But I will avoid changing history.
